# Local Dependencies

Install these before running the app locally.

## Required

- Node.js 20 LTS or newer
- npm, included with Node.js

This project includes a `package-lock.json`, so npm is the recommended package manager for local setup.

## Install

From the project folder, run:

```bash
npm install
```

## Run Locally

Start the development server:

```bash
npm run dev
```

Vite will print the local URL in the terminal, usually:

```text
http://localhost:5173/
```

## Optional Checks

Run tests:

```bash
npm test
```

Run linting:

```bash
npm run lint
```

## Main App Packages

The app is built with:

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui and Radix UI components
- React Router
- TanStack Query
- Zustand
- Vitest
